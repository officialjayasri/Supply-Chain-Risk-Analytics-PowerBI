# Supply Chain Performance & Risk Analytics Dashboard

## Project Overview

Developed an interactive Power BI dashboard to analyze supply chain performance and risks. Collected, cleaned, transformed, and modeled data using Power Query and DAX. Created KPIs for shipments, delays, inventory, supplier performance, lead time, and risk to support data-driven decision-making.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel
- Data Modeling

## Key KPIs

- Total Shipments
- Delay Rate %
- Average Lead Days
- Cost per Shipment
- Inventory Turnover
- Supplier Performance
- Supply Chain Risk Score
